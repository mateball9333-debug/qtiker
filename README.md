# Qtiker

Qtiker is a small Qt Widgets clicker game for Linux.

It keeps the interface compact: click, buy simple upgrades, get passive income,
and keep progress between launches through `QSettings`.

## Build and Run

Requirements:

- CMake 3.16+
- C++ compiler
- Qt 6 Widgets
